Quickstart: Connecting in 60 Seconds

BloxCloud is a plug-and-play Backend-as-a-Service (BaaS) and LiveOps platform designed specifically for Roblox games. With a single Luau module, your game servers stream real-time physics FPS, memory diagnostics, cross-server matchmaking queues, and emergency remote kill-switches.

Mandatory Roblox Studio Setting
Roblox Studio blocks outbound cloud HTTP requests by default. Before testing:
Roblox Studio → Home → Game Settings → Security → Turn ON "Allow HTTP Requests" → Save
2

SDK Installation

  1. In the Roblox Studio Explorer panel, right click ReplicatedStorage → Insert Object → ModuleScript.
  2. Rename the ModuleScript to BloxCloud.
  3. Open BloxCloud, delete all placeholder code, and paste the source from BloxCloud.luau.
  4. In ServerScriptService, create a regular Script (e.g., BloxCloudInit) and initialize with your studio secret API key: 
local BloxCloud = require(game.ReplicatedStorage.BloxCloud).Init("bc_live_your_api_key", {
    baseUrl = "https://bloxcloud.world",
    pollingInterval = 5 -- Seconds between liveops updates
})

print("⚡ BloxCloud connected successfully!")

Fleet Telemetry & Diagnostics

Roblox does not provide cross-server fleet health metrics in real time. BloxCloud automatically measures Physics FPS (workspace:GetRealPhysicsFPS()), Memory MB (StatsService:GetTotalMemoryUsageMb()), and player counts every 15 seconds.

Custom Error Logging

Unhandled script crashes are hooked automatically via ScriptContext.Error. You can also report custom errors manually: 

-- Manually log a runtime error to the cloud sentry
BloxCloud.Telemetry:ReportError({
    message = "DataStore Save Failure for Player 10928",
    stack = debug.traceback(),
    scriptName = "SaveManager"
})

LiveOps & Emergency Kill-Switches

Found an economy exploit or a game-breaking weapon bug? Toggle feature flags instantly from your web dashboard without publishing a game update or restarting live servers. 

-- Check a flag synchronously (returns cached value)
local isDoubleXp = BloxCloud.LiveOps:GetConfig("double_xp_active", false)

-- Listen for real-time remote updates without server restart
BloxCloud.LiveOps:OnConfigChange("disable_plasmagun", function(newValue, oldValue)
    if newValue == true then
        warn("🚨 EMERGENCY: Plasmagun disabled by studio admin!")
        -- Unequip and lock weapon for all players
        for _, player in ipairs(game.Players:GetPlayers()) do
            local gun = player.Backpack:FindFirstChild("Plasmagun")
            if gun then gun:Destroy() end
        end
    end
end)

-- Listen for global announcements broadcast from the dashboard
BloxCloud.LiveOps:OnBroadcast(function(broadcast)
    print("📢 GLOBAL ALERT: " .. broadcast.message)
    -- Display UI banner to all players in server
end)

Ranked Matchmaking & Cross-Server ELO

Pair players across all running game servers by skill rating with automatic dynamic tolerance windows (+30 ELO every 2 seconds). 

local ARENA_PLACE_ID = 1234567890 -- Your match arena PlaceId

-- 1. Queue a player for Ranked Matchmaking
local success, ticket = BloxCloud.Matchmaking:JoinQueue(player, "Ranked_1v1", {
    rating = player.leaderstats.ELO.Value -- e.g. 1350
})

-- 2. Handle Match Found Event
BloxCloud.Matchmaking:OnMatchFound(function(player, match)
    print("⚔️ MATCH FOUND! Match ID: " .. match.matchId)
    print("   Team A Avg Rating: " .. match.avgRatingA .. " vs Team B Avg Rating: " .. match.avgRatingB)

    -- Coordinates Roblox TeleportService:ReserveServer(ARENA_PLACE_ID) across servers
    -- and teleports all matched players into the same private arena instance:
    BloxCloud.Matchmaking:TeleportToMatch(player, match, ARENA_PLACE_ID)
end)

-- 3. Leave Queue (if player steps off matchmaking pad)
BloxCloud.Matchmaking:LeaveQueue(player)

Global Auction House & Anti-Dupe Locks

Enable cross-server item trading across your universe. BloxCloud uses server-side atomic mutex locking so two players can never purchase or duplicate the same item at the same millisecond. 

-- 1. List an item globally across all servers
local ok, listing = BloxCloud.Marketplace:ListGlobalItem(
    player, 
    "frost_katana_mythic", 
    { level = 50, damage = 180 }, 
    15000 -- Price in coins
)

-- 2. Fetch active cross-server listings
local listings = BloxCloud.Marketplace:GetActiveListings()
for _, item in ipairs(listings) do
    print(item.itemId .. " listed by " .. item.sellerName .. " for " .. item.price)
end

-- 3. Atomically buy an item (Atomic anti-dupe guarantee)
local success, boughtItem = BloxCloud.Marketplace:BuyGlobalItem(buyerPlayer, listing.listingId)
if success then
    print("✔ Purchase complete! Gave item to: " .. buyerPlayer.Name)
else
    warn("✖ Purchase failed (Already sold or locked)")
end

REST API Reference

All game server requests must include the x-api-key header with your studio API key. Rate limit: 600 requests per minute per key.

Method Endpoint Description
POST /api/v1/telemetry/heartbeat Report server FPS, memory, and player count
GET /api/v1/liveops/config Fetch active feature flags and studio broadcast
POST /api/v1/matchmaking/queue Enqueue a player by skill rating and queue type
GET /api/v1/matchmaking/ticket/:id Poll matchmaking status and match assignment
POST /api/v1/matchmaking/match/:id/server-code Coordinate Roblox ReserveServer() access code across servers
POST /api/v1/marketplace/list Create a cross-server auction house listing
POST /api/v1/marketplace/buy Atomically purchase listing with anti-dupe lock
